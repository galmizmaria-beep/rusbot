# Лото · Студия учебных игр

Рабочая браузерная версия редактора по `TZ_redaktor_Loto.md`. Не требует установки, сборки, сервера, регистрации или подключения к интернету.

## Открыть редактор

Дважды нажмите **«Редактор Лото.html»** и откройте файл в браузере. `index.html` — тот же редактор для размещения на статическом хостинге.

В редакторе уже подготовлен пример: три классических билета, 15 заданий, четыре типа ответов. В подвале размещена точная надпись:

> Все права защищены и принадлежат Гальмиз Марии Александровне

## Инструкция для учителя

1. **Дизайн.** Измените название и описание. Выберите цветовую тему, фон, системный шрифт, цвета билетов, размер текста и скругление.
2. **Задания.** Добавьте или скопируйте задание. Доступны один ответ, несколько ответов, ввод текста и правильная последовательность. В вариантах выбора отметьте правильные ответы. Для последовательности порядок в редакторе является эталоном. Для ввода укажите допустимые ответы по одному на строке.
3. **Билеты.** Выберите билет и клетку, назначьте задание из списка. Пустые клетки декоративные. Классический билет содержит 3 × 9 клеток и ровно по пять заданий в каждой строке. Учебный билет имеет произвольную сетку от 2 × 2 до 5 × 9. Изменение сетки сохраняет задания в банке.
4. **Бочонки.** Настройте дерево, цвета игровых состояний, окно задания и кнопку проверки.
5. **Герой.** Загрузите PNG, WebP или JPEG, настройте размер и положение. В режиме редактирования героя можно перемещать мышью. Эффекты включаются отдельно для наведения, верного ответа, ошибки и победы.
6. **Правила.** Укажите жизни, символ жизни, диапазон билетов. Максимум билетов не может превышать количество подготовленных билетов. Нажмите «Проверить перед экспортом».
7. **Экраны.** Измените приветствие, тексты победы и поражения и подписи кнопок.
8. Переключитесь в **Тест** и пройдите игру. В режиме редактирования нажатие клетки открывает соответствующее задание. Выбор экрана сверху позволяет увидеть оформление без начисления очков.
9. **Сохранить проект** скачивает `.loto.json` для дальнейшего редактирования. **Загрузить** восстанавливает проект. История отмены хранит до 120 действий.
10. **Скачать HTML** создаёт автономную игру. Передайте файл ученику — он открывается в браузере без редактора и без интернета.

Черновик сохраняется в браузере с задержкой 650 мс. При следующем запуске предлагается восстановление. Браузер может ограничивать локальное хранилище и размер сохраняемых ресурсов: статус ошибки виден в верхней панели. Файл проекта остаётся основным способом переноса и резервного сохранения.

## Оптимизация и Genially

**Облегчить код** создаёт отдельную экспортную копию: убирает неиспользуемые задания, уменьшает изображения до выбранного разрешения, применяет WebP с заданным качеством и показывает фактические размеры до/после. Прозрачность сохраняется, исходный проект не меняется. Если изображений нет, облегчённый файл может иметь тот же размер — это нормально.

**Код для Genially** принимает HTTPS-адрес уже опубликованной игры. Сначала скачайте HTML и разместите его на статическом хостинге, разрешающем iframe. Укажите URL, ширину и высоту, скопируйте iframe. Локальный файл не является адресом публикации. При недоступности буфера обмена код можно выделить и скопировать вручную.

Публикация на хостинге и в аккаунте Genially не выполнялась. Встраивание необходимо проверить в целевом аккаунте.

## Комплект

- `Редактор Лото.html` — автономный редактор;
- `index.html` — его копия для хостинга;
- `exports/Демонстрационный проект.loto.json` — редактируемый пример;
- `exports/Математическое лото.html` — автономная игра;
- `exports/Математическое лото — облегчённое.html` — облегчённый экспорт примера;
- `src/` — исходные HTML, CSS и JavaScript;
- `build.py` — сборка автономного редактора средствами Python 3;
- `tests/core.test.js` — автоматические проверки игровой логики и экспорта;
- `ACCEPTANCE.md` — результаты и границы проверки;
- `PROJECT_FORMAT.md` — формат переносимого проекта.

## Разработка

```sh
python3 build.py
node tests/core.test.js
```

Сборка не требует сторонних пакетов. Node.js нужен только для тестов. Код движка общий для предпросмотра и экспортированной игры. При изменении файлов в `src/` повторите сборку.

## Дизайн и границы версии

Редактор: тёмная рабочая область, боковая навигация, лавандовые акценты и большая область предпросмотра. Игра: светлые билеты, объёмные деревянные бочонки, зелёный стол и золотистые кнопки. Ориентиры в сети:

- [«Лото Онлайн», версия для ПК](https://play.google.com/pc-store/games/details?hl=ru&id=com.rstgames.loto);
- [«Русское лото», браузерная версия](https://minigames.mail.ru/loto);
- [«Лото на русском», браузерная игра](https://yandex.ru/games/app/327162).

Реализована собственная CSS-графика по мотивам компьютерного лото. Исходные иллюстрации и логотипы сторонних игр в проект не включены.

Эта версия не является подтверждением выполнения всех критериев ТЗ. В частности, пока доступны русский интерфейс и четыре системных шрифта (Arial, Verdana, Georgia, Trebuchet MS); переводы EN/UK/KK и встроенные Nunito/Roboto/Open Sans не добавлены. Используются общие настройки скругления и типографики, без всех отдельных параметров рамок/теней/состояний каждого элемента. На финальных экранах настраиваются тексты; отдельная загрузка изображений для каждого финального экрана не реализована. Оптимизация выполняет асинхронное кодирование изображений, но не использует Worker и не минифицирует исходники. Эффект тонирования героя — тёплый фильтр со свечением, не произвольная окраска силуэта. Перемещение бочонка представлено анимацией появления на клетке.

Подробности проверки и внешние ограничения — в `ACCEPTANCE.md`.
