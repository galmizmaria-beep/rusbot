# Лото · Студия учебных игр 1.6

Откройте **«Редактор Лото.html»** в браузере. Установка и интернет для редактора, формул и автономной игры не нужны. `index.html` — тот же редактор для размещения на сайте.

## Изменения версии 1.6

- Полная формулировка открывается нажатием на клетку, а не наведением. В «Заданиях» включайте или выключайте «Показывать полную формулировку при нажатии». Старые задания сохраняют включённую настройку. Клетки, закрытые бочонком, больше не открывают формулировку. Если формулировка отключена, медиа задания остаются доступны рядом с ответами.
- В игре реплики расположены над героем. В разделе «Герой» регулируются размеры имени и реплик (10–36 px). На титульном листе герой с репликой стоит непосредственно над кнопкой начала игры.
- Цвета билета, клеток, текста и скругление находятся в «Билетах». Размер бочонка (48–120 px) — в «Бочонках». Добавлены отступы для рамки выбранного бочонка.
- Библиотека GIF доступна для героя, короткой подписи, задания и вариантов ответа: шесть встроенных анимаций и GIF, уже загруженные в проект. Работает без интернета.
- Новый и скопированный билет сразу открываются для редактирования и в предпросмотре. Максимум выбираемых на старте билетов увеличивается вместе с количеством билетов, до шести; его можно изменить в «Правилах».

Откройте свой проект в версии 1.6 и замените код Genially новым.

## Изменения версии 1.5

- Герой с репликами находится слева. В широкой правой колонке бочонки расположены над билетом. Панели имеют постоянные размеры; появление ответов не меняет размер сцены.
- Нижнее окно полного задания убрано. Наведите указатель на клетку или перейдите к ней клавишей Tab, чтобы прочитать задание с формулами, картинками и аудио. На сенсорном экране коснитесь клетки. Кнопка «ⓘ Задание» закрепляет подсказку; крестик или Escape закрывают её.
- В редакторе перетаскивайте клетки мышью или пальцем — в миниатюре билета и в большом предпросмотре. Занятые клетки меняются местами, пустая принимает задание. С клавиатуры: Alt + стрелки. Переносятся все связанные изображения, формулы и ответы.
- Расположение сохраняется в черновике, JSON и экспортированной игре. «Обратно» отменяет перестановку. Если нарушено правило пяти заданий в строке классического билета, он автоматически становится учебным со свободным расположением.

Для ранее вставленной игры откройте свой проект в версии 1.5 и замените код Genially новым.

## Точечные изменения версии 1.4

- **Задания → Аудиозадание → Нужны ответы к аудиозаданию:** учитель выбирает режим. Если ответы выключены, ученик слушает запись и нажимает «Прослушано»; клетка завершается без оценки и потери жизни. Варианты ответа сохраняются и возвращаются при включении переключателя.
- На титульном экране убраны девиз «Учись · Играй · Побеждай» и подпись «Учебное лото».
- **Экраны → Стартовый экран:** отдельные ползунки размера названия (24–80), инструкции (12–36) и вопроса о количестве билетов (12–36).
- Под **«Короткая подпись клетки»** доступны картинка и GIF. Они видны прямо в билете, текст можно оставить или удалить. Изображения автоматически сжимаются; GIF остаются анимированными.
- Герой занимает собственную колонку слева от билета. Ограничение 52 px снято: размер регулируется до 250 px в пределах постоянной сцены. Окно бочонков справа сужено до 290 px.
- **Герой → Реплики героя:** приветствие, выбор задания, выполнение, ошибка, победа, поражение. Изменение реплики открывает соответствующий экран предпросмотра. Авторские реплики сохраняются в проекте и не переводятся при смене языка; кнопка возврата стандартных реплик восстанавливает автоматический перевод.

Для уже вставленной игры замените код Genially кодом из версии 1.4 после открытия своего проекта.

## Исправления версии 1.3

- Формулы `$…$` и `$$…$$` распознаются в клетках билета сразу, ещё до выбора задания. Формулы и пояснение задания расположены в области билета. В окне бочонков нет дублирующего вопроса.
- Сцена всегда 1280 × 720; масштаб зависит только от размера iframe. Билет, описание и ответы занимают постоянные области, открытие задания не сдвигает поле. Длинное содержимое уменьшается внутри своей области.
- Фон покрывает весь viewport слайда, включая свободное пространство вокруг сцены. Применяется заполнение с обрезкой краёв, без цветных полос и скругления внешней рамки.
- «Бочонки → Появление ответов»: без анимации, плавное появление, снизу, мягкое увеличение; длительность 100–1500 мс. Анимация срабатывает при открытии задания, не при каждом выборе ответа. Системная настройка уменьшения движения учитывается.
- «Билеты → Фон билета и клеток»: два независимых цвета.
- Черновик проекта сохраняется в IndexedDB, рассчитанной на проекты с медиа. Старые черновики из localStorage доступны для восстановления. Незаконченные задания не мешают восстановлению черновика. Ошибка записи явно показывается.
- Рисунки карандашом сохраняются вместе с черновиком редактора, не исчезают при изменении оформления или переключении экранов. В экспортированной игре рисунок сохраняется в браузере отдельно, если встраивание разрешает доступ к хранилищу; при закрытом хранилище остаётся в текущем сеансе.

Чтобы получить исправления в ранее вставленной игре, откройте свой проект в версии 1.3 и замените код Genially новым. Оптимальный формат слайда — 16:9. Автосохранение относится к тому же браузеру и адресу редактора; файл `.loto.json` остаётся переносимой копией.

## Новое в версии 1.2

- Игра масштабируется по ширине и высоте iframe без прокрутки. Билеты переключаются кнопками над полем с сохранением прогресса.
- В задания и варианты ответа можно загрузить картинки, GIF и аудио. Изображения сжимаются автоматически, GIF сохраняют анимацию. Если перекодирование увеличило размер, остаётся оригинал. Аудио до 15 МБ встраивается без перекодирования.
- «Готовый текст»: текстовый вопрос, на который ученик вводит ответ. Допустимые ответы задаются по строкам; дополнительный материал для чтения необязателен. «Аудиозадание»: запись с ответами или без них — по выбору учителя.
- Отдельные цвета вопроса и ответа, три дизайна бочонков и собственное изображение.
- Крестик у каждого билета; подтверждение удаления кнопками «Удалить» / «Оставить».
- Черновик с карандашом, цветом, толщиной, ластиком, отменой и очисткой.
- Редактор остаётся русским при смене языка игры. Формулы отображаются в клетках билетов и описании заданий.

Для уже вставленной игры в Genially заново скопируйте код и замените старое встраивание. Длинный текст вписывается в собственную область: размер всего поля не меняется. Для читаемости большие материалы лучше разделить на несколько заданий.

## Возможности редактора

- Код для Genially появляется сразу; его можно скопировать без предварительной публикации игры. Для локального HTML предусмотрены резервное копирование и скачивание кода в `.txt`.
- «Облегчить код» открывает настройки **кода Genially**, уменьшает изображения и сжимает встроенную игру. Размер и процент уменьшения показываются для кода в текущем окне; исходный проект сохраняется.
- В разделе «Дизайн → Языки» доступны русский, английский, украинский и казахский. Выбор языка меняет игровые надписи. Редактор остаётся русским. Авторские задания не переводятся.
- Доступны 15 шрифтов. Nunito, Roboto и Open Sans встроены вместе с кириллицей и казахскими буквами, остальные используют установленные системные шрифты.
- Размеры клетки, вопроса и ответа регулируются отдельно. Вопрос и ответ: 12–48 px.
- Исправлен фон стола: удалён некорректный цвет в CSS-градиенте, разделены изображение, слой сукна и затемнение.
- **Непрозрачность сукна 0%** полностью открывает загруженное изображение; 100% закрывает его цветом сукна. Затемнение регулируется отдельно.
- Редактирование сохраняет выбранную клетку и экран. Сцена обновляется в существующих DOM-элементах. Изменение оформления не сбрасывает ответы и прогресс теста; изменение эталонов и правил явно сбрасывает тестовую сессию.
- Герой размещается в отдельном блоке. На старте он приветствует ученика; во время игры думает, подбадривает и радуется вместе с ним. Показывается общий прогресс, а билеты и бочонки остаются свободными.
- Нажатие клетки открывает типы задания и поля выбранного вопроса. Можно создать задание в пустой клетке прямо из предпросмотра. Копирование задания при выбранной клетке назначает ей новую копию.
- Поддерживается LaTeX в подписях клеток и тексте заданий. Формулы отображаются сразу и работают без сети.

## Как создать игру

1. **Дизайн:** название, инструкция, языки, фон, шрифты и размеры.
2. **Билеты:** выберите клетку в миниатюре или в большом предпросмотре. Нажмите тип задания; в разделе «Задания» редактируются текст и ответы именно выбранной клетки.
3. **Задания:** один ответ, несколько ответов, ввод текста, правильный порядок, аудиозадание и готовый текст. Правильные варианты отмечаются слева. Для порядка последовательность в редакторе — эталон. Для ввода допустимые ответы задаются по одному на строке.
4. **Герой:** загрузите персонажа, задайте имя, размер, прозрачность и экраны появления. Положение безопасное, без свободного наложения поверх игрового поля.
5. **Правила:** жизни и число билетов. Классический билет требует по пять заданий в каждой из трёх строк. Для произвольной сетки используйте учебный шаблон.
6. **Экраны:** настройте приветствие, победу и поражение. При редактировании финального текста открывается соответствующий экран предпросмотра.
7. **Тест:** пройдите игру как ученик. **Сохранить проект** скачивает `.loto.json`; **Скачать HTML** — автономную игру.

В банке одно задание может использоваться несколькими клетками: изменение общего задания отражается во всех связанных клетках. Если нужен отдельный вариант, выберите клетку и нажмите «Копировать» в редакторе задания.

Черновик автоматически сохраняется в браузере, история отмены хранит до 120 действий. При недоступности или переполнении хранилища отображается ошибка; сохраняйте резервные копии через «Сохранить проект». Проекты первой версии автоматически получают новые настройки.

## Математическая запись

Пишите формулу между `$…$`, а отдельную крупную формулу — между `$$…$$`:

```text
Вычислите $\frac{1}{2}+\frac{1}{2}$.
$\sqrt{x}$
$x^{10}+a_{n+1}$
$\sum_{i=1}^{n}i$
$$\begin{cases} x+y=5 \\ x-y=1 \end{cases}$$
```

Под вопросом есть кнопки вставки и «Все шаблоны». Выберите поле подписи клетки, вопроса или материала для чтения, затем нужный шаблон. Ошибка LaTeX не ломает игру: запись будет показана текстом с подсветкой.

Это математическая **вёрстка**, а не система вычислений. Для текстового ответа задайте все допустимые формы, например `1/2`, `0,5` и `0.5`, отдельными строками. Доступны настройки регистра, «е/ё» и пробелов.

## Genially

В одном окне доступны два способа:

- **Игра целиком — код без ссылки:** iframe с `srcdoc`. Код готов сразу. «Облегчить код» уменьшает изображения, удаляет неиспользуемые задания и сжимает HTML в gzip с загрузчиком. Уменьшается именно копируемый код. Для распаковки нужен современный браузер с `DecompressionStream`.
- **Ссылка на опубликованную игру:** обычный iframe с HTTPS-адресом. Скачайте игру из этого же окна и разместите её по указанному адресу на хостинге, разрешающем встраивание. После оптимизации нужно заменить опубликованный HTML; короткая ссылка iframe почти не изменится.

«Проверить код» позволяет запустить iframe прямо в редакторе. Если браузер запрещает буфер обмена, редактор выделяет код и предлагает Ctrl/Cmd+C либо скачивание `.txt`.

**Genially может удалять `srcdoc` или ограничивать длину/содержимое кода.** Если встроенный вариант не сохраняется или не запускается после публикации, используйте HTTPS-режим. Тест в редакторе не заменяет проверку в опубликованном Genially; доступа к целевому аккаунту не было.

## Файлы и сборка

- `Редактор Лото.html`, `index.html` — готовый редактор;
- `exports/` — проект-пример, автономная игра и код встраивания;
- `src/` — исходники;
- `vendor-assets.zip` — закреплённая локальная копия KaTeX 0.16.22 и встроенных шрифтов;
- `vendor/*LICENSE*`, `vendor/*OFL*`, `THIRD_PARTY.md` — лицензии зависимостей;
- `tests/` — проверки логики, формул, предпросмотра, копирования и кода Genially;
- `ACCEPTANCE.md` — результаты и границы проверки.

```sh
python3 build.py
npm install
npm test
```

Сборка использует только Python 3 и при необходимости извлекает `vendor-assets.zip`. Загрузка зависимостей из сети при сборке не требуется. `npm install` нужен только для тестового DOM-окружения LinkeDOM.
