# Формат `.loto.json`, версия 1

UTF-8 JSON, корневой объект:

| Поле | Назначение |
| --- | --- |
| `version` | Версия схемы, сейчас `1` |
| `title`, `description` | Название и описание стартового экрана |
| `questions` | Банк заданий с устойчивыми `id` |
| `tickets` | Билеты с устойчивыми `id` |
| `rules` | Жизни, значок, формат жизней, минимальное и максимальное число билетов |
| `design` | Цвета, шрифт, размеры, фон и параметры кнопки |
| `hero` | Встроенное изображение, координаты, размер, прозрачность и события эффектов |
| `screens` | Тексты начала игры, победы, поражения и повторного запуска |

Задание: `id`, `type` (`single`, `multiple`, `text`, `order`), `text`, `label`, `stamp`, `explanation`, `options`, `answers`, `caseSensitive`, `yo`, `spaces`.

Вариант ответа: `id`, `text`, `correct`. Для `single` верен ровно один вариант, для `multiple` — точный набор. Для `order` порядок массива `options` является эталоном. `answers` — массив допустимых строк для текстового ввода.

Билет: `id`, `name`, `template` (`classic` / `learning`), `rows`, `cols`, `cells`. Массив `cells` хранится построчно. Элемент равен `id` задания либо `null` для декоративной клетки. Повторное использование одного задания разрешено; игровой прогресс имеет ключ `ticket.id:cellIndex`.

Изображения встроены как `data:image/png;base64,...`, `data:image/jpeg;base64,...` или `data:image/webp;base64,...`. Внешние URL не принимаются. При загрузке изображения проверяется сигнатура файла, размер до 10 МБ и возможность декодирования. Максимум 40 мегапикселей. Импорт проекта ограничен 35 МБ.

Сеанс ученика, порядок перемешивания, ответы, жизни сеанса, история отмены и состояние интерфейса не включаются в файл проекта. Файл содержит авторские правильные ответы и не предназначен для секретных экзаменационных заданий.

Импорт сначала разбирается и проверяется, затем заменяет текущий проект. Неподдерживаемая версия, повреждённые ссылки, повторные ID, некорректные сетки, цвета, ресурсы и невозможные условия игры отклоняются. Текущий проект при ошибке не изменяется.

## Дополнения версии редактора 1.1

Схема по-прежнему имеет `version: 1`; загрузчик дополняет старые проекты безопасными значениями по умолчанию:

- `language`, `editorLanguage`: `ru`, `en`, `uk`, `kk`, по умолчанию `ru`;
- `design.questionSize`, `design.answerSize`: 12–48 px, по умолчанию 22;
- `design.tableOpacity`: 0–100%, по умолчанию 0 — изображение не закрывается цветом сукна;
- `hero.placement`: `both`, `start`, `game`, по умолчанию `both`;
- `hero.name`: необязательное имя напарника.

`hero.x/y` сохраняются для обратной совместимости, но свободное наложение героя заменено безопасным блоком в потоке документа. Формулы хранятся как обычный текст LaTeX с разделителями `$` или `$$`, включая JSON-экранирование обратных слешей. Эталон текстового ответа не вычисляется как математическое выражение.
