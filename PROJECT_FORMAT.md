# Формат `.loto.json`, версия 1

UTF-8 JSON, корневой объект:

| Поле | Назначение |
| --- | --- |
| `version` | Версия схемы, сейчас `1` |
| `title`, `description` | Название и описание стартового экрана |
| `questions` | Банк заданий с устойчивыми `id` |
| `tickets` | Билеты с устойчивыми `id` |
| `rules` | Жизни, значок, формат жизней, минимальное и максимальное число билетов |
| `design` | Цвета, шрифт, размеры, фон и параметры кнопки |
| `hero` | Встроенное изображение, координаты, размер, прозрачность и события эффектов |
| `screens` | Тексты начала игры, победы, поражения и повторного запуска |

Задание: `id`, `type` (`single`, `multiple`, `text`, `order`, `audio`, `passage`), `text`, `label`, `stamp`, `explanation`, `options`, `answers`, `caseSensitive`, `yo`, `spaces`.

Вариант ответа: `id`, `text`, `correct`. Для `single` верен ровно один вариант, для `multiple` — точный набор. Для `order` порядок массива `options` является эталоном. `answers` — массив допустимых строк для текстового ввода.

Билет: `id`, `name`, `template` (`classic` / `learning`), `rows`, `cols`, `cells`. Массив `cells` хранится построчно. Элемент равен `id` задания либо `null` для декоративной клетки. Повторное использование одного задания разрешено; игровой прогресс имеет ключ `ticket.id:cellIndex`.

Изображения встроены как `data:image/png;base64,...`, `data:image/jpeg;base64,...` или `data:image/webp;base64,...`. Внешние URL не принимаются. При загрузке изображения проверяется сигнатура файла, размер до 10 МБ и возможность декодирования. Максимум 40 мегапикселей. Импорт проекта ограничен 90 МБ.

Сеанс ученика, порядок перемешивания, ответы, жизни сеанса, история отмены и состояние интерфейса не включаются в файл проекта. Файл содержит авторские правильные ответы и не предназначен для секретных экзаменационных заданий.

Импорт сначала разбирается и проверяется, затем заменяет текущий проект. Неподдерживаемая версия, повреждённые ссылки, повторные ID, некорректные сетки, цвета, ресурсы и невозможные условия игры отклоняются. Текущий проект при ошибке не изменяется.

## Дополнения версии редактора 1.1

Схема по-прежнему имеет `version: 1`; загрузчик дополняет старые проекты безопасными значениями по умолчанию:

- `language`, `editorLanguage`: `ru`, `en`, `uk`, `kk`, по умолчанию `ru`;
- `design.questionSize`, `design.answerSize`: 12–48 px, по умолчанию 22;
- `design.tableOpacity`: 0–100%, по умолчанию 0 — изображение не закрывается цветом сукна;
- `hero.placement`: `both`, `start`, `game`, по умолчанию `both`;
- `hero.name`: необязательное имя напарника.

`hero.x/y` сохраняются для обратной совместимости, но свободное наложение героя заменено безопасным блоком в потоке документа. Формулы хранятся как обычный текст LaTeX с разделителями `$` или `$$`, включая JSON-экранирование обратных слешей. Эталон текстового ответа не вычисляется как математическое выражение.

## Дополнения редактора 1.2

`editorLanguage` нормализуется в `ru`, выбор `language` влияет только на игру.
`design.questionColor` и `design.answerColor` — HEX-цвета; `barrelSkin` — `oak`, `walnut`, `gold`; `barrelImage` — data URL пользовательского изображения.

Задания и варианты имеют `media: {image: "", audio: ""}`. Изображения: PNG, JPEG, WebP, GIF. Аудио: data URL MIME `audio/mpeg`, `audio/wav`, `audio/ogg`, `audio/mp4` или `audio/webm`. Для `audio` запись обязательна, ровно один вариант правильный. Для `passage` ответ проверяется по `answers`, как при `text`; поле `passage` — необязательный материал для чтения.

GIF: до 350 кадров, 16 Мп на холст, 160 млн пикселей суммарно. Размер при загрузке уменьшается до 640 px по большей стороне (меньше для вариантов и бочонков). Анимация сохраняется. Формулы визуализируются в `question.label`, `question.text` и `question.passage`.

## Дополнения редактора 1.3

`design.answerAnimation`: `none`, `fade`, `rise`, `zoom`, по умолчанию `fade`. `design.animationDuration`: 100–1500 мс, по умолчанию 350.

Геометрия сцены фиксирована: 1280 × 720. Фон всегда заполняет весь слайд; старое `design.fit` сохраняется в JSON для совместимости, но в игре используется `cover`. `design.ticket` и `design.cell` задают фоны билета и клеток.

Автоматический черновик — запись `{project, scratch}` в IndexedDB. Это отдельное хранилище редактора, не изменение версии `.loto.json`. Незавершённые задания сохраняются; полнота проверяется при запуске и экспорте игры. Рисунки ученика не включаются в экспортируемый проект.

## Дополнения редактора 1.4

`question.answerRequired`: boolean, по умолчанию `true`. Для аудиозадания значение `false` отключает варианты и проверку; метод завершения клетки не снимает жизнь. `options` сохраняется и может быть пустым. Запись по-прежнему обязательна.

`question.labelMedia: {image: ""}`: изображение или GIF для клетки, отдельно от медиа полного задания. При наличии картинки текст `label` может быть пустым. Правила валидации изображения такие же, как для остальных ресурсов.

`design.titleSize`: 24–80 (по умолчанию 47); `instructionSize` и `chooseSize`: 12–36 (по умолчанию 14). Размеры заданы в логических пикселях постоянной сцены.

`hero.lines`: объект со строковыми ключами `hello`, `thinking`, `cheer`, `encourage`, `won`, `lost`. Отсутствующий ключ использует стандартную реплику языка игры, пустая строка скрывает текст реплики. Все новые поля переносятся через JSON и автономный экспорт; версия схемы остаётся 1.

## Дополнения редактора 1.5

Новых полей нет. Перестановка меняет порядок `tickets[].cells`, сохраняя идентификаторы заданий и связанные медиа. При нарушении правила пяти заданий в каждой строке классического билета `template` становится `learning`. Положение всплывающей подсказки — состояние интерфейса, в JSON не сохраняется.
